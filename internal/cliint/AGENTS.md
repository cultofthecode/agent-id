# internal/cliint

The `gh` shim (#23): `agent-id cli <binary> -- <args>` runs the provider's known CLI with a fresh token for one call. Spec: `.ai/specs/2026-11-13-gh-shim.md`; requirements: `.ai/specs/capabilities/gh-shim.md`. Every change here is `risk-high` and `security`: it hands a token to another program.

- **Launcher.** `activation.LauncherScript` is the file that `exec` puts first on `PATH` as `gh`. It holds no token and no profile and calls `"$AGENT_ID_BIN" cli gh -- "$@"`. Without a usable binary it exits 125 and never starts the real `gh`.
- **Fail closed, in this order:** agent context, provider binary, recursion marker, the adapter's rules (`Activator.CheckCLI`), neutral directories, the real CLI on `PATH`, `Ready`, the provider (the key), the token, the environment. No step before the last starts the CLI. A refusal exits 125 with one line: `agent-id: AID-<CLI>-<KIND>: <message>`.
- **Never an empty token.** `BuildEnv` refuses an empty value for a provider variable. A token manager error, an empty token, or a bad provider environment is `AID-GH-TOKEN`, not a run with the decoy or the developer's login.
- **Core only.** Imports `internal/provider`, `internal/token`, cobra, and the standard library (depguard `cliint-uses-only-the-ports`). It names no forge and no `gh`: the binary, variables, decoys, host pin, and rules come from the provider. Do not import `internal/activation`: the composition root passes the neutral directories in.
- **Rules belong to the adapter.** The deny-list and the host check are `provider/github/cli.go`, a pure function with hostile-input tables. The core only maps a `*provider.CLIRefusal` to a `Refusal`.
- **No secret leaves the package.** A reason for a token failure is a fixed phrase per error class (`reasonFor`); an unknown error is `an unexpected failure`. Text from the profile, the key, or the neutral directories passes `Scrub`. No logger. The token is only in the environment of the real CLI.
- **The real CLI.** `FindCLI` walks `PATH`, skips relative entries, the launcher directory, and any file that is the same file as the launcher (link or hard link). The marker `AGENT_ID_CLI_ACTIVE` stops a `gh` that starts `gh` through `PATH`. A path that `PATH` offers to an agent is a documented bypass (brief §10).
- **Tests** call `testenv.Isolate(t)`, use `providertest.Fake` and `FakeActivator`, a recording `Execer`, and fake tokens. The process tests are in `cmd/agent-id/ghshim_test.go` and `failclosed_test.go`. Nothing reaches a network.
